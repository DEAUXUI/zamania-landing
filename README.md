# Лендинг «Замания» — праздник «Всё включено»

Статичный сайт (HTML + CSS + JS), без сборки. Открывается двойным кликом по `index.html`.

## Структура
```
index.html            — страница
css/style.css         — стили и адаптив (десктоп ≥1200, планшет 900–1199, телефон <900)
js/main.js            — ссылка для кнопок «Забронировать», анимации
images/               — картинки и иконки (скачиваются скриптом)
fonts/                — шрифты Actay (нужно положить самостоятельно)
download-images.sh    — скачать картинки из Figma (Mac/Linux)
download-images.ps1   — то же для Windows
assets.txt            — список картинок для скриптов
```

## Что сделать перед публикацией
1. **Картинки.** Запустите `download-images.sh` (или `.ps1` на Windows). Ссылки Figma действуют ~7 дней
   (примерно до 9 ноября 2026). Если истекли — экспортируйте из Figma вручную с именами из `assets.txt`.
2. **Шрифты.** Положите в `fonts/` файлы `ActayWide-Bold.woff2` и `Actay-Regular.woff2`
   (подойдут .woff или .otf с теми же именами). Без них сайт работает на запасных шрифтах.
3. **Ссылка бронирования.** В `js/main.js` впишите `BOOKING_URL`.
4. **Соцсети.** В `index.html` в подвале замените `href="#"` у двух иконок.

## Публикация (бесплатно)
- **Netlify Drop:** откройте https://app.netlify.com/drop и перетащите папку проекта — сайт получит адрес вида `*.netlify.app`.
- **GitHub Pages:** загрузите файлы в репозиторий → Settings → Pages → Branch: `main`, папка `/root`.
- Свой домен подключается в настройках выбранного хостинга.
